# Deterministic Tafel refit summary

The canonical dataset contains 97 curves. All 97 completed deterministic QC and model selection successfully; no canonical curve is excluded.

The `images/` directory contains one self-contained QC figure per curve. Files
are named `record_NNN__curve_<curve_id>__qc.png`; all table `sample_record`
values use the same canonical 1–97 record IDs. `qc_review_queue.csv` lists
focused visual checks without changing fit eligibility.
