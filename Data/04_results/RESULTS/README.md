# Released results

This directory contains the numerical tables, quality-control records,
frozen model outputs, and reports released with the paper.

## Directory map

- `01_PPC_REVIEW/`: Bayesian local-line posterior predictive checks and review table.
- `02_TAFEL_CURVE_QC/`: deterministic Tafel curve quality-control tables and images.
- `03_TARGET_COMPARISON/`: target distributions and literature comparison.
- `04_MODEL/`: selected PRESTO model and policy outputs.
- `05_WORKBOOKS/`: frozen model-training and feature-analysis workbooks.
- `06_FEATURE_IMPORTANCE/`: feature-reliance and ALE result tables.
- `07_REPORT/`: released report files and delivery record.
- `08_DATA_EXPORTS/`: human-readable released data exports.

The section numbers are unique and continuous. Files in this directory are
frozen outputs; rerunning the workflow writes new artifacts under the output
area rather than modifying these released results.
